# Pacman-Clone-Python-Projeto-de-IPRP---Universidade-de-Coimbra
Este projeto consiste numa recriação funcional do clássico jogo Pacman, desenvolvido integralmente em Python no âmbito da unidade curricular de Introdução à Programação e Resolução de Problemas (IPRP). O desenvolvimento teve como foco a consolidação rigorosa de fundamentos de ciência da computação, com ênfase na estruturação lógica de algoritmos, controlo de fluxo e manipulação de estruturas de dados matriciais.

Principais Destaques Técnicos

Tecnologia: Algoritmos programados em Python (deves especificar no README se utilizaste bibliotecas auxiliares, como o Pygame ou a Turtle, para a renderização gráfica).

Mecânicas Base: Implementação do ciclo principal do jogo (game loop), gestão do estado das variáveis globais e atualização em tempo real do ecrã.

Lógica Computacional: Desenvolvimento das regras de colisão em ambientes de grelha 2D, sistema de pontuação e comportamento autónomo (movimentação) dos fantasmas.
