# Pacman in Python

A playable Pacman clone written in **Python**, developed for the Introduction to Programming course (IPRP) at the University of Coimbra.

## ✨ Features
- Real-time game loop with continuous screen updates
- Grid-based collision detection (walls, pellets, ghosts)
- Ghost movement logic
- Scoring system
- Centralized game state management
